# RAYKA Buoy Gateway

اپلیکیشن اندروید که پیامک‌های تله‌متری بویه‌های دریایی خودتان را (که با پیشوند `RAYKA:` روی سیم‌کارت‌های خودتان می‌رسند) می‌خواند و به سرور Supabase و/یا یک سرور محلی می‌فرستد — با رضایت و اطلاع کامل شما، روی گوشی خودتان.

## معماری

```
بویه دریایی --SMS--> گوشی شما (سیم‌کارت انتخابی) --App--> صف محلی (Room DB)
                                                              │
                                   اینترنت وصل است؟ ─── بله ──┼──> Supabase Edge Function ──> جدول telemetry
                                                              │
                                                            نه
                                                              │
                                                              ▼
                                       سرور محلی (مودم/هات‌اسپات/خودِ گوشی) ──> PWA شما می‌خواند
                                                              │
                                               به‌محض وصل‌شدن اینترنت
                                                              ▼
                                                 ارسال خودکار به Supabase
```

## نکات کلیدی طراحی

- **چند سیم‌کارت:** در تنظیمات اپ، سیم‌کارت‌هایی که باید زیر نظر گرفته شوند را تیک می‌زنید؛ پیامک از سیم‌های دیگر نادیده گرفته می‌شود.
- **فیلتر پیامک:** فقط پیامک‌هایی که با پیشوند تنظیم‌شده (پیش‌فرض `RAYKA:`) شروع شوند پردازش می‌شوند؛ پیامک‌های شخصی دست‌نخورده باقی می‌مانند.
- **هیچ پیامی گم نمی‌شود:** هر پیامک ابتدا در یک دیتابیس محلی (Room) ذخیره می‌شود و فقط بعد از تأیید ارسال موفق به ابر از صفِ «ارسال‌نشده» خارج می‌شود. اگر گوشی خاموش شود یا ری‌استارت شود، بعد از روشن‌شدن دوباره (`BootReceiver`) صف باقی‌مانده ارسال می‌شود.
- **فوریت اتصال مجدد:** یک `NetworkMonitor` به محض وصل‌شدن اینترنت بلافاصله صف را خالی می‌کند؛ منتظر تایمر بعدی نمی‌ماند.
- **مسیر محلی وقتی اینترنت نیست:** اگر آدرس یک سرور محلی تنظیم شده باشد (روی مودم، هات‌اسپات گوشی دیگر، یا حتی خودِ همین گوشی)، هر پیام ارسال‌نشده به ابر موازی به آنجا هم فرستاده می‌شود تا PWA بدون اینترنت هم داده‌ی تازه ببیند.
- **خودِ گوشی به‌عنوان سرور محلی:** با روشن‌کردن یک سوییچ در تنظیمات، خودِ همین گوشی یک HTTP سرور کوچک روی یک پورت بالا می‌آورد (`GET /telemetry`) تا PWA مستقیماً از آی‌پی همین گوشی در شبکه‌ی محلی بخواند.
- **امنیت کلیدها:** طبق همان توصیه‌ای که خودتان در schema گذاشته بودید، از anon key برای insert استفاده نمی‌شود؛ اپ دقیقاً مثل Tasker با یک رمز مشترک (`X-Tasker-Secret`) به Edge Function وصل می‌شود، و همه‌ی این تنظیمات فقط رمزنگاری‌شده روی خود گوشی ذخیره می‌شوند.

## راه‌اندازی

1. `supabase/schema.sql` را (اگر قبلاً اجرا نکرده‌اید) در SQL Editor پروژه‌ی Supabase اجرا کنید.
2. `supabase/functions/ingest-buoy-sms/index.ts` را دیپلوی کنید:
   ```bash
   supabase functions new ingest-buoy-sms
   # محتوای index.ts را جایگزین کنید
   supabase secrets set TASKER_SHARED_SECRET=<یک رشته‌ی رمزی دلخواه>
   supabase functions deploy ingest-buoy-sms
   ```
3. این Repository را در GitHub بسازید (Private) و فایل‌ها را طوری Upload کنید که `app/` و `.github/` مستقیماً در ریشه باشند.
4. در تب Actions روی «Build RAYKA Buoy Gateway APK» بروید، «Run workflow» را بزنید و بعد از سبزشدن، APK را از Artifacts بگیرید.
5. روی گوشی نصب کنید؛ صفحه‌ی رضایت را تأیید کنید؛ سیم‌کارت(ها) را انتخاب کنید؛ آدرس Edge Function و رمز مشترک را وارد کنید؛ در صورت نیاز آدرس سرور محلی یا سوییچ «خودِ گوشی سرور محلی باشد» را هم تنظیم کنید؛ سپس دروازه را روشن کنید.
6. فایل‌های `pwa/` همان داشبورد شماست که از قبل دارید — بدون تغییر، هم به Supabase و هم (در حالت آفلاین) به سرور محلی وصل می‌شود.

## پوشه‌ها

- `app/` — اپ اندروید (دروازه‌ی پیامک به سرور)
- `supabase/` — اسکیمای دیتابیس و Edge Function شما (بدون تغییر نسبت به چیزی که داشتید)
- `pwa/` — داشبورد PWA شما (بدون تغییر)
- `local-server/` — یک سرور محلی اختیاری و مستقل (Node.js) برای وقتی می‌خواهید سرور محلی روی دستگاه دیگری غیر از گوشی اصلی باشد
