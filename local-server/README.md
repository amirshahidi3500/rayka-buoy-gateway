# سرور محلی اختیاری

اگر می‌خواهید سرور محلی روی یک دستگاه جدا از گوشی اصلی باشد (مثلاً یک رزبری‌پای، لپ‌تاپ، یا گوشی قدیمی با Termux که به همان مودم/هات‌اسپات وصل است)، از این اسکریپت استفاده کنید.

```bash
node server.js
# یا با رمز مشترک:
LOCAL_SECRET=my-secret PORT=8787 node server.js
```

سپس در تنظیمات اپ Android:
- **آدرس سرور محلی** = `http://<آی‌پی این دستگاه در شبکه>:8787/ingest`
- **رمز مشترک محلی** = همان `LOCAL_SECRET`

و در PWA، آدرس `http://<همان آی‌پی>:8787/telemetry` را برای گرفتن آخرین داده‌ها در حالت آفلاین اضافه کنید.

اگر نمی‌خواهید دستگاه جداگانه‌ای داشته باشید، در تنظیمات اپ Android گزینه‌ی «خود این گوشی سرور محلی باشد» را روشن کنید — در این حالت خود گوشی روی پورت انتخابی همین کار را انجام می‌دهد و نیازی به این اسکریپت نیست.
